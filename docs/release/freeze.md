# v1.0.0 封存说明

基准日期：2026-10-26（Asia/Shanghai）。封存标记：v1.0.0。保留此标签指向的提交；后续修订建立新提交和新标签，不移动封存标签。

源码仓库只提交干净白名单导出：共用框架、两平台接入、插件、测试、空白配置模板、原生桥接源码与指定DLL、使用文档和已脱敏视频。运行状态、个人配置、账号数据、数据库、日志和服务器凭据均不纳入。

SHA256SUMS列出交付文件摘要；它自身不包含在摘要列表内。可用 `python tools/check_frozen_release.py` 校验。发布脚本 `tools/export_release.py --target <干净目录>` 不会自动拷贝根目录真实配置或运行目录。

本版沿用上游非商业使用许可，修改内容见CHANGELOG。使用介绍视频中的管理台为合成配置演示，真实群聊素材已裁剪脱敏。功能存在和端到端验收分开记录，见feature-matrix.md；未通过真人验证的Windows新增功能不宣称已验收。

实际测试结果见TEST_REPORT.md。既有Linux服务不因本次源码导出停止；新源码的运行变化应在独立测试环境验收后再替换部署。
