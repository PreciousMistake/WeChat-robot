# 使用手册

## 1. 准备与启动

准备微信小号，加入自己的测试群；启动对应平台客户端并完成登录，再启动管理台。Windows入口是 `web.py`；Linux按部署说明启动接收、模型和管理台服务。管理台绑定回环地址，远程使用SSH转发或受保护反向代理，不直接暴露到公网。

## 2. 配置云服务

填写聊天服务的地址、模型与密钥。聊天模型和音频模型分别配置；文本接口应兼容OpenAI Chat Completions。ASR使用千问Message模型（北京地域）；TTS可选MiniMax/Fish Audio、模型和音色。不要将服务商A的密钥填给服务商B。密钥留空通常保留旧值，更换地址必须填对应密钥。

## 3. 加入群配置

在群设置中选择小号已加入的群并保存。只有已配置且启用的群会触发机器人；多个群独立维护人格、上下文、主人和接话限制。Linux独立插件默认跟随全部已启用群；Windows插件默认范围也会受核心群支持列表约束，自定义范围仍应核对。

## 4. 人格与主人

从人格库选择预设，或添加自己的正文；获取参考人设可点击页面中的GitHub链接。每群选择“机器人主人”，只能从真实成员中选定；不设置表示本群没有确认主人。群成员自称、改名、引用和 `/绑定 昵称` 不会改变主人绑定，后者只是成员显示称呼。保存后新任务采用新配置；正在发送的消息无法追溯撤回。

## 5. 自然聊天

启用自然聊天后直接对机器人说话，无需每次艾特。模型会区分明确对话、主动参与和忽略。每群冷却与每小时上限用于主动接话，不代表每条群消息都必须回复。先用草稿模式检查模型行为，再开启真实发送。

## 6. 语音

配置ASR服务并为目标群启用语音识别。每群回复方式可选文字、跟随输入、语音或两者。配置TTS音色后，用5–10秒语音在测试群检查识别、回复内容和播放。听不到声音时分别检查接收、转写和合成状态，不要只修改聊天模型。

## 7. 生图

开启独立生图服务，填写地址、模型和密钥。自然说“帮我画一只太空鲸鱼”，或者发送 `/画图 一只太空鲸鱼`。

| 服务 | 地址示例 | 模型示例 |
|---|---|---|
| OpenAI兼容 | 服务商给出的 `/v1` 基址或完整 `/images/generations` | 服务商明确支持的生图模型 |
| 阿里百炼Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-image-2.1-turbo` |
| MiniMax | `https://api.minimax.cn/v1/image_generation` | `image-01` |

官方地址可选自动协议；第三方代理按其协议明确选择。MiniMax不使用OpenAI图片路径；Qwen官方采用原生同步接口。私有异步任务接口不在本版范围内。每次一张、按群限额；超时和不确定结果不自动重新生成。失败后先检查记录，确认后再发新请求。

## 8. 插件

常用命令：`/来张图`、`/美女`、`成语接龙`、`看图猜成语`、`提示`、`公布答案`、`/绑定 昵称`、`/总结 昵称`、`/总结群聊`、`test`。插件接管指令后，普通AI不再重复回复。图库是从图库取图，与AI创作图片不同。看图游戏进行中，先按当前游戏规则操作；不要把普通AI聊天当作游戏回合。

## 9. 排查与停止

先看群启用状态、自然聊天总开关、草稿模式、服务心跳和模型配置。Linux微信弹窗、窗口尺寸、输入框草稿或目标不确定都会阻止自动发送。不要同时人工操纵发送窗口。结果不确定时先核对实际群聊，避免重复发送。

Windows在管理台停止机器人再退出服务。Linux先暂停回复，再按需停止接收与AI服务；关闭网页不等于停止机器人。完整后台日志与数据库是私人数据，不要直接上传GitHub。
