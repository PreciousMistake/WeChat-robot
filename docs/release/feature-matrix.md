## 接入方式

Windows 使用指定微信构建的原生桥接。Linux 从授权账号的本地数据库接收消息，发送由客户端桌面操作完成，并以原始微信出站记录核对回执。Linux不是完全基于微信协议的机器人，保持图形会话、窗口状态与客户端登录仍然必要。
